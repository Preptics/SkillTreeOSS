# Code of Conduct

SkillTreeOSS has adopted the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. It applies in the repository (issues, pull requests, discussions, reviews), on the site's community features, and anywhere you represent the project.

In short: be welcoming, assume good faith, critique work rather than people, and do not harass anyone.

## Reporting

Report unacceptable behaviour privately to **support@preptics.com** with "SkillTreeOSS conduct" in the subject. Reports are read by the maintainers at Preptics LLC, who maintain the project, and are kept confidential. Maintainers may remove comments, close threads, or block accounts that break the code of conduct, following the Contributor Covenant's enforcement guidelines.
